Patterns per wave

Lift-and-shift, re-platform, re-architect, greenfield, hybrid and open-lakehouse — recommended per workload wave from the harvested estate, with confidence, rationale and recorded dissent.

Read-only extraction agent

Runs in your network, harvests catalogs, code and query logs from SQL Server, Oracle and Teradata, and ships only metadata. A kill-test proves it cannot write.

ETL and schedulers, not just SQL

SSIS and Informatica mappings become tested dbt projects; Control-M and SQL Agent schedules become Snowflake task graphs or Airflow DAGs.

AI remediation under review

Every AI change carries confidence, rationale, model and prompt version, and lands as a pull request with generated tests. Nothing is promoted without a named reviewer.

L0–L5 validation

Schema, counts, aggregates, row hashes, KPI parity and performance parity by table tier — with normalisation rules as data and mismatches clustered to their known issue.

Go/no-go evidence packs

Reconciliation by tier, performance vs SLA, grant mapping, rehearsed rollback and sign-offs — generated from snapshots. Decommissioning is blocked while legacy consumers remain.

Snowflake Foundation (greenfield)

A 6–10 week landing zone generated as Terraform from a reviewed role and warehouse model, followed by a first data product end to end — with Package O Core from day one.

  • Access → functional roles; never object privileges to users
  • Warehouses per workload class with monitors and auto-suspend
  • Tag-based masking, network rules, budgets, agent roles
  • 31 automated Well-Architected checks with remediation playbooks
